# Білім туралы

Минималистичный авторский сайт об образовании на Astro. Основной язык — казахский.

## Быстрый запуск

1. Установить Node.js 20.3+ (рекомендуется Node.js 22 LTS).
2. В терминале открыть папку проекта.
3. Выполнить `npm install`.
4. Выполнить `npm run dev`.
5. Открыть адрес, который покажет терминал (обычно http://localhost:4321).

Проверка production-сборки: `npm run build`. Результат будет в `dist/`.

## Как добавить эссе

Создать файл `src/content/essays/your-slug.md`, используя существующий пример как шаблон. Поля `title`, `description`, `date`, `category`, `tags` обязательны (tags может быть пустым списком). `draft: true` скрывает публикацию.

## Как добавить заметку

Создать Markdown-файл в `src/content/notes/` по примеру.

## Как добавить ресурс

Поместить PDF/DOCX/PPTX в `public/files/` и создать Markdown-файл в `src/content/resources/`. В поле `file` указать путь `/files/имя-файла.pdf`. Если файл ещё не готов, поле `file` не указывать — кнопка скачивания не появится. Не размещать чужие закрытые учебные материалы без прав на распространение.

## Перед публикацией

- Заменить `https://example.com` в `astro.config.mjs` на реальный адрес сайта.
- Проверить все тексты и источники: пример эссе — редакционный черновик, не проверенная окончательная статья.
- Заполнить страницу автора.
- Удалить или дополнить демонстрационные карточки.
- Проверить мобильный вид, ссылки и документы.

## Хостинг

Cloudflare Pages: подключить GitHub-репозиторий, build command `npm run build`, output directory `dist`. Сайт статический; база данных и сервер не нужны.
